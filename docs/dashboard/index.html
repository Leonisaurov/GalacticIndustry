Reglas, definiciones de estado y fuente de datos
Panel estático y autocontenido. El selector de versiones, la línea de tiempo y la plantilla dinámica se generan desde el tracker embebido para file://; estilos y lógica viven en dashboard.css y dashboard.js. Funciona sin servidor, CDN ni red. Si se abre por HTTP, actualiza los datos desde IMPLEMENTATION_TRACKER.json sin recargar la página. Para actualizar los datos: python3 tools/sync-dashboard.py, que también regenera STATUS.md. Mapa de sistemas: INDEX.md. Coordinación: CONCURRENCY.md.
